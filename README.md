# Enterprise Network Infrastructure Deployment & Field Engineering

This repository documents field engineering methodologies, deployment runbooks, standard operating procedures (SOPs), and configuration standards for physical network installations, wireless access point (AP) cutovers, switch provisioning, and remote administration.

---

## 🛠️ Key Capabilities & Hands-on Scope

- **Wireless Access Point (AP) Deployment:** Wall/ceiling physical mounting, patch cable termination, PoE/PoE+ verification, and provisioning/controller adoption.
- **Switching & Rack Hardware:** 19-inch server rack mounting, cable management, patch panel mapping, trunk/access port configuration, and VLAN tagging.
- **Remote Terminal & CLI Management:** Serial console & SSH management via PuTTY, CLI troubleshooting, firmware upgrades, and off-site coordination using Webex, MS Teams, and TeamViewer.
- **Field Cutovers:** Executing end-of-life hardware replacement, VLAN tag testing, port security validation, and post-installation connectivity verification.
